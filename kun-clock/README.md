# 坤时 · 下班宇航局

一个不依赖第三方前端库的单文件下班倒计时。界面为深色荧光绿、动态轨道球体与分段进度条，适配桌面和手机。

## 访问与部署

应用文件：`public/kun/index.html`。

Vite 构建会把 `public/` 中的文件原样复制到输出目录。现有 Vercel 部署成功后，访问站点的 `/kun/index.html` 即可；不改变原有首页、路由或依赖。

也可把该 HTML 单独放到任意静态托管服务器，或下载后用浏览器打开。全部样式和脚本都内嵌，不依赖外部字体、图片、API、追踪脚本或网络时间服务。

## 默认规则

- 北京时间 UTC+8，使用设备时钟；不随设备时区改变。
- 周一至周五，09:00 上班，18:30 下班。
- 1 坤时 = 2.5 小时 = 150 分钟 = 9,000,000 毫秒。
- 倒计时为距当天结束时刻的自然时间，不扣午休。
- 上班前显示到当天结束的剩余时间，班次进度为 0。
- 到点后归零；休息日显示休息状态；北京时间跨天自动重新判断。
- 节假日与调休不自动识别，可在设置中把今天标为补班或休息，今日例外在跨天后失效。
- 当前仅支持同日班次；下班时间必须晚于上班时间。
- 坤时显示三位小数，未到点前最小显示 0.001；实际时分秒向上取整，避免提前显示已经下班。

## 操作

右上角设置按钮可修改班表和当日例外；月亮按钮开启静谧模式；桌面端可全屏。支持复制当前倒计时，及手动提前庆祝。工作状态跨过结束时刻时会自动庆祝一次；减少动态效果或静谧模式下不播放粒子效果。

设置通过浏览器 localStorage 保存，键为 `kun-clock-v1`，不跨浏览器或设备同步。存储被禁用时仍可运行，但设置不会持久保存。系统减少动态效果设置会被尊重，隐藏标签页时停止持续动画。

## 验证

对独立页面执行了 JavaScript 语法检查、Chromium 渲染和 320/360/390/760/900/1440 像素布局检查。测试覆盖 18:30 临界点、凌晨跨天、周末、今日补班和例外过期；设备时区设为 Asia/Tokyo 时仍显示北京时间。设置读写测试使用模拟 Storage；没有把该测试当作真实公网浏览器的存储持久性保证。

核心纯函数可通过 `window.KunClock.model(epochMilliseconds, settings)` 测试，不改变页面真实倒计时。
